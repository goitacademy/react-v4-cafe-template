# Sip Happens Café — шаблон домашнього завдання 2

Шаблон для домашнього завдання 2 курсу React v4: віджет відгуків кав'ярні.

## Що вже є в шаблоні

- проєкт на Vite: React, TypeScript, React Compiler, ESLint;
- встановлені `modern-normalize` і `clsx`; у `src/main.tsx` підключено `modern-normalize` і глобальні стилі `src/global.css`;
- компонент `App` у `src/components/App/App.tsx`;
- готові стилі всіх компонентів у файлах `.module.css` у папках `src/components`.

Стилі писати не треба. Файли компонентів `.tsx` ти створюєш сам, поруч з їхніми стилями.

## Як почати

1. Натисни **Use this template** → **Create a new repository** і створи репозиторій `02-react-cafe` у своєму акаунті.
2. Склонуй свій репозиторій і встанови залежності:

   ```bash
   npm install
   ```

3. Запусти проєкт:

   ```bash
   npm run dev
   ```

## Перевірка перед здачею

```bash
npm run lint
npm run build
```

Обидві команди мають виконатися без помилок.
